## ✨ Fitur Unggulan

- 🎛️ **Studio Cinema & Fullscreen Visualizer**: Tampilan piringan vinyl presisi dengan panggung visualisasi dinamis (Neon Pillars, Cyber Wave, Stardust Pulse).
- 🎤 **Sing-Along Dynamic Lyrics & Auto-Romaja**: Lirik tersinkronisasi baris demi baris secara *real-time* lengkap dengan transliterasi Romaja (Korea), Romaji (Jepang), dan Pinyin (Mandarin).
- 🧑‍🎤 **Halaman Showcase & Diskografi Artis**: Jelajahi profil dan seluruh katalog lagu resmi dari penyanyi favorit dengan transisi mulus.
- 🤖 **Suno AI Music Studio (v3.5 / v4)**: Ciptakan lagu berkualitas studio dari prompt teks atau lirik kustom Anda sendiri.
- 🛡️ **Enterprise Security Suite**: Terlindungi dengan Security Headers (CSP, NoSniff, FrameGuard), Rate Limiting Anti-DDoS, Anti-SSRF, dan Sanitasi Input.

## 💻 Menjalankan dari Kode Sumber (Development)

Jika ingin menjalankan aplikasi langsung dari source code:

```bash
# 1. Clone repositori
git clone https://github.com/BizleeRav/Project-Aplikasi-Music.git
cd Project-Aplikasi-Music

# 2. Install dependensi
npm install

# 3. Jalankan server lokal
npm start
```

Akses di browser Anda:
- **Laptop / PC**: `http://localhost:3000`
- **HP (Wi-Fi lokal)**: Buka alamat IP laptop Anda pada port `3000` (misal `http://192.168.x.x:3000`).
